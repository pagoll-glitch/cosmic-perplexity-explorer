# Lotus Garden – Elegant Intelligence
### Interactive Perplexity Explorer for Autoregressive Language Models

Lotus Garden is an educational AI application designed to demystify language model mathematics, token prediction, probability distributions, and perplexity.

## Features
- **Real In-Browser AI Inference**: Autoregressive next-token probability prediction using DistilGPT-2 via Transformers.js (WebAssembly / ONNX).
- **Interactive Token Ribbon & Deep Inspector**: Inspect per-token confidence, negative log likelihood (nats), self-information (bits), and the model's top-5 candidate predictions.
- **Manual Simulation & Formula Explorer**: Interactive calculator showing geometric mean calculation steps and the N-sided die metaphor.
- **Theme**: Luxury botanical stationery design with pink lotus illustrations, warm ivory paper cards, architectural mint arches, and textured sage-green background.
- **Pure Static Frontend**: Built in pure vanilla web technologies (`index.html`), zero build steps required, ready for immediate deployment on Vercel, GitHub Pages, or Netlify.

## Deployment on Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other** (Static HTML).
3. Root Directory: `./` (or leave default).
4. Click **Deploy**.
